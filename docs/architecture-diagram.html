📊 Tổng quan Hệ thống

TicketBook là hệ thống đặt vé sự kiện được xây dựng theo kiến trúc Microservices, với API Gateway làm điểm vào duy nhất cho tất cả các request từ client.

Component Port Công nghệ Mô tả
🚪 Gateway 4000 Express.js, http-proxy Reverse proxy, static files, auth guard
🔐 Auth Service 4101 Express.js, Prisma, JWT Đăng ký, đăng nhập, quản lý user
📅 Events Service 4102 Express.js, Prisma, Socket.IO Events, shows, orders, payments, tickets
🐘 PostgreSQL 5432 PostgreSQL 15 Database chính
💾 Redis 6379 Redis 7 Seat holds, session cache
🌐 Frontend - HTML/CSS/JS (Vanilla) SPA-like với multiple pages

🌐 Frontend Modules

7 UI modules: HomePage, LoginUI, SeatmapUI, PurchaseUI, MyTicketUI, DashboardUI, InspectorUI

HTML5 CSS3 JavaScript

💳 Payment Providers

Tích hợp MoMo và VNPay với webhook callbacks để xử lý thanh toán realtime

MoMo VNPay

⚡ Real-time Features

Socket.IO cho cập nhật ghế realtime, Redis cho seat holds với TTL 15 phút

Socket.IO Redis

🔒 Security

JWT authentication, Helmet middleware, CORS configuration, Rate limiting

JWT Helmet bcrypt
